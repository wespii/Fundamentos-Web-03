# Computación en la nube

Mini sitio web colaborativo para la asignatura Fundamentos WEB, grupo 4303.

## Integrantes y distribución

| Integrante | Responsabilidad |
|---|---|
| Alejandro Lopez | Computación en la nube |
| Santiago Guizado | Internet de las Cosas IoT |
| Jonathan Gonzales | Ciberseguridad |

## Descripción

El sitio explica conceptos actuales de la computación en la nube mediante tres páginas HTML conectadas. Cada integrante desarrolla inicialmente una página y participa en la revisión e integración del trabajo.

## Estructura

- `index.html`: Computación en la nube.
- `tema2.html`: Internet de las cosas IoT.
- `tema3.html`: página de Jonathan Gonzales.
- `img/`: imágenes utilizadas por las páginas.

## Reglas del proyecto

El sitio utiliza HTML5, Git y GitHub. No utiliza CSS, JavaScript, Bootstrap ni frameworks.
